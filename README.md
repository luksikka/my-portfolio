# Vijayakumar Luksikka - Portfolio Website

A modern, responsive personal portfolio website showcasing my skills, projects, and experience as an Information Technology student.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean and professional design with smooth animations
- **Interactive Navigation**: Fixed navbar with smooth scrolling
- **Project Showcase**: Detailed presentation of three major projects
- **Skills Display**: Organized categorization of technical and soft skills
- **Contact Form**: Integrated email contact functionality
- **Smooth Animations**: Intersection Observer API for scroll-triggered animations
- **Mobile Menu**: Hamburger menu for mobile navigation

## Sections

1. **Home/Hero**: Eye-catching introduction with call-to-action buttons
2. **About**: Professional summary and career objectives
3. **Skills**: Comprehensive list of technical skills and technologies
4. **Projects**: Detailed showcase of major projects including:
   - Rooms & Lands Rental System
   - E-Waste Collecting System
   - Fitness App
5. **Education**: Academic background and qualifications
6. **Contact**: Multiple ways to get in touch

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- JavaScript (ES6+)
- Font Awesome Icons
- Intersection Observer API

## Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. That's it! The site is ready to view

## Customization

To customize this portfolio for your own use:

1. **Personal Information**: Update all personal details in `index.html`
2. **Colors**: Modify CSS variables in `:root` section of `styles.css`
3. **Content**: Replace project descriptions, skills, and education details
4. **Images**: Add your own profile picture and project images
5. **Contact**: Update email and phone number throughout the site
